# Portfolio delivery

Read `AGENTS.md`, `docs/BACKLOG.md` and `docs/DECISIONS.md` first. Pick the highest-value unblocked ticket and confirm its acceptance check. For parallel work, route tickets using `agents/README.md`; give each role one owned artifact and avoid concurrent writes to canonical files.

Keep professional, personal, OSS and planned evidence separate. Use only reviewed public inputs; do not import private source material. Make the primary reading path and genuine replay work statically before considering live inference.

Before a PR or release, use the gates in `SECURITY.md` and `docs/RESILIENCE.md` that apply to the change. Report the ticket, changed files, check results, unresolved risks and next action. An external publication still needs Wael's approval of the inspected artifact.
